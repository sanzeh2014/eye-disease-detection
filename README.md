# Eye Disease Detection

Eye disease detection using deep learning. ResNet50 model for diabetic retinopathy classification with Grad-CAM explainability.

## Performance
- Accuracy: 73.1%
- Quadratic Weighted Kappa: 0.68
- Cross-dataset accuracy drop: 4.9%

## Datasets
- APTOS 2019 (3,662 images)
- IDRiD (516 images with pixel annotations)
- Messidor-2 (1,748 images)
